동영상 중복 제거기 - 도움말

같은 영상의 여러 버전 중 가장 좋은 품질만 남기고 나머지를 정리합니다.

1. 프로그램 소개

  • 자동 중복 탐지 (프레임 지각 해시 기반)
  • 품질 비교 후 최고 품질만 보존
  • 삭제 전 체크박스로 수동 조정 가능 (유지 파일도 체크 시 삭제 가능)
  • 삭제는 휴지통 이동 (실패 시 바탕화면 백업 폴더)
  • 하위 폴더 포함 스캔 지원
  • FFmpeg 자동 설치 지원

2. 실행 방법 (exe 배포판)

  1. VideoDedup.exe 를 더블클릭합니다. 설치 과정 없이 바로 실행됩니다.
  2. 처음 실행 시 FFmpeg가 없으면 자동 다운로드 여부를 묻습니다. "예"를 선택하면 약 110MB를 다운로드해 자동 설치합니다.
별도의 Python 설치나 소스코드는 필요 없습니다. exe 하나로 동작합니다.

로그 창스캔/삭제 과정과 오류를 기록합니다.

4. 사용 순서 (단계별)

  1. 폴더 선택: "찾아보기" 버튼을 눌러 동영상이 들어 있는 폴더를 선택합니다.
  2. 옵션 설정: 하위 폴더 포함 여부, 샘플 프레임 수, 유사도 임계값을 조정합니다.
  3. 스캔 시작: "스캔 시작" 버튼을 누릅니다. 중단하려면 "중지"를 누릅니다.
  4. 결과 확인: 중복 그룹별로 파일이 나열됩니다. 초록색 "유지"는 남길 파일, 빨간색 "삭제 예정"은 지울 파일입니다. 체크박스로 개별 선택을 바꿀 수 있으며, 유지 파일도 체크하면 삭제됩니다.
  5. 삭제 실행: "선택한 파일 삭제" 버튼을 누르고 확인합니다. 선택된 파일이 휴지통으로 이동합니다 (실패 시 바탕화면 백업 폴더).
  6. 복원: 휴지통 또는 바탕화면 _삭제된_중복영상 폴더에서 복원할 수 있습니다.

5. 품질 비교 기준

같은 그룹 안에서 아래 순서로 점수를 비교해 가장 높은 파일 1개를 "유지"로 정합니다.

  1. 해상도 (픽셀 수) - width x height가 클수록 좋음
  2. 비트레이트 - 높을수록 화질이 좋음
  3. 파일 용량 - 같은 길이라면 클수록 정보량이 많음
  4. 프레임 레이트 (FPS)

6. 중복 판별 방식

  • 영상 길이가 비슷한 파일끼리 후보로 묶습니다 (±2초 또는 1%).
  • 각 영상에서 균등 간격으로 프레임을 샘플링해 지각 해시(pHash)를 계산합니다.
  • 프레임 해시의 평균 해밍 거리가 임계값 이하이면 "같은 영상"으로 판단합니다.

7. 옵션 상세

옵션기본값권장 조정
샘플 프레임 수8정확도를 높이려면 12~16, 속도를 높이려면 4~6
유사도 임계값12압축 차이가 큰 중복은 15~20, 오탐이 많으면 8~10
임계값을 너무 높이면 서로 다른 영상이 같은 그룹으로 묶일 수 있습니다. 결과를 꼭 확인하세요.

8. 지원 형식

mp4, mkv, avi, mov, wmv, flv, webm, m4v, mpg, mpeg, ts, m2ts, 3gp

9. FFmpeg 자동 설치

  • 프로그램 실행 시 FFmpeg가 없으면 자동으로 다운로드/설치할지 묻습니다.
  • 약 110MB 다운로드 (인터넷 필요)
  • 진행률과 다운로드량이 표시됩니다
  • 설치 후에는 "FFmpeg 확인됨" 로그가 나타납니다
  • 나중에 설치하려면 "FFmpeg 자동 설치" 버튼을 누르세요

수동 설치 방법

  1. https://www.gyan.dev/ffmpeg/builds/ 에서 ffmpeg-release-essentials.zip 다운로드
  2. 압축 해제 후 bin 폴더를 원하는 위치에 둡니다 (예: C:\ffmpeg\bin)
  3. 시스템 환경 변수 Path에 해당 bin 폴더 경로를 추가
  4. 새 명령 프롬프트에서 ffmpeg -version, ffprobe -version으로 확인

10. 문제 해결 (FAQ)

Q. 스캔이 너무 느려요.

A. 샘플 프레임 수를 4~6으로 줄이거나, 하위 폴더 옵션을 끄고 작은 폴더부터 스캔하세요.

Q. 같은 영상인데 그룹으로 묶이지 않아요.

A. 유사도 임계값을 15~20으로 올려보세요.

Q. 다른 영상인데 같은 그룹으로 묶였어요.

A. 유사도 임계값을 8~10으로 낮추세요. 삭제 전 반드시 결과를 확인하세요.

Q. 삭제가 안 돼요 / WinError가 나요.

A. 휴지통 이동을 우선 시도하고, 실패 시 바탕화면 _삭제된_중복영상 폴더로 이동합니다. 파일이 사용 중이거나 잠겨 있으면 실패할 수 있습니다.

Q. exe 실행 시 보안 경고가 떠요.

A. "추가 정보 - 실행"을 선택하세요. (서명되지 않은 exe의 정상 경고입니다.)

11. 주의사항

  • 삭제는 휴지통 이동이지만, 대량 삭제 전에는 반드시 결과를 확인하세요.
  • 스캔 중 CPU와 디스크를 사용합니다. 다른 무거운 작업과 동시에 실행하지 마세요.
  • 네트워크 드라이브의 파일은 휴지통 이동이 실패할 수 있습니다. 이 경우 백업 폴더로 이동합니다.
